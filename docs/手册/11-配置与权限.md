## 构建配置

### `wxt.config.ts`

- `extensionApi: 'chrome'`
- **函数式 manifest**（按 `env.mode` 分流）：

  | 模式 | 扩展名 | 说明 |
  | --- | --- | --- |
  | `development`（`npm run dev`） | 限时特卖助手（开发版） | 描述含「需保持 npm run dev 终端开启，否则弹窗白屏」 |
  | `production`（`npm run build`／`zip`） | 限时特卖助手 | 描述「虾皮卖家后台限时特卖自动化工具」 |

- `version: '1.14.3'`
- Vite alias：`@` → 项目根目录

**为什么用函数式 manifest**：dev 版与生产版弹窗行为完全不同（dev 依赖本地开发服务器），名字不同才能在 `chrome://extensions` 里一眼分清。

### `web-ext.config.ts`

```ts
defineWebExtConfig({ disabled: true })
```

**原因**：dev 时不自动打开浏览器 —— 否则每次 `npm run dev` 都会弹出一个全新的干净 Chrome 配置，用户的登录态不在里面，无法测试。

### `components.json`

shadcn/ui 配置：`baseColor=slate`、`cssVariables=true`、`tsx=true`，别名指向 `components/`、`utils`、`ui`。

### `tailwind.config.ts`

Content 路径：`entrypoints/**/*.{ts,tsx}`、`components/**/*.{ts,tsx}`。

`theme.extend` **不是空的** —— 定义了三类：
- `colors`：品牌色（`shopee-brand` = Teal `#0D9488`、`brand-dark`、`brand-light`）+ shadcn CSS 变量色
- `borderRadius`
- `keyframes` + `animation`

`plugins: []`。

### `postcss.config.js`

标准 PostCSS：`tailwindcss` + `autoprefixer`。

### `package.json`

- `name`: `limited-time-sale`
- `version`: `1.14.3`（与 `wxt.config.ts` 一致）
- 脚本：见 [`10-环境与命令.md`](./10-环境与命令.md)

### `tsconfig.json`（根）

`target=ESNext`、`moduleResolution=Bundler`、`jsx=react-jsx`、`strict=true`、`baseUrl=.`、`paths: @/* → ./*`，includes 含 `wxt.config.ts`。

### `tsconfig.json`（backend）

`strict=true`、`moduleResolution=Bundler`、`outDir=./dist`。

## 扩展权限

`wxt.config.ts` 中声明的 manifest 权限（**实测 6 项**）：

| 权限 | 用途 |
| --- | --- |
| `storage` | 缓存、内部状态、auth |
| `cookies` | 读 SPC_CDS |
| `scripting` | 注入页面主世界 fetch |
| `alarms` | 定时任务与自动模式调度 |
| `unlimitedStorage` | 商品数量大时不撞配额 |
| `downloads` | 导出模板 JSON、导出自动模式日志 |

**host_permissions**：`['https://*.shopee.tw/*']` —— **仅**虾皮台湾站。

> 生产构建**不会**多出 `http://localhost/*`（那是 dev 构建才可能有的）；改动后应重新核对。

## 环境变量

### 插件（构建时烤进产物）

| 变量 | 作用 | 用到的地方 |
| --- | --- | --- |
| `VITE_BACKEND_URL` | 后端主地址（构建时烤进产物） | `background.ts`（`DEFAULT_BACKEND_URL`）、`backend-api.ts`、`store.ts` |
| `VITE_BACKEND_FALLBACK_URL` | 主地址不可达时的兜底地址 | `background.ts`、`backend-api.ts` |
| `VITE_DEBUG_LOGS` | `'true'` 时输出 `[init]`／`[render]`／`[diagnostic]` 日志 | popup |

### 后端（运行时读 `backend/.env`）

| 变量 | 作用 |
| --- | --- |
| `PORT` | 监听端口，默认 `5724` |
| `JWT_SECRET` | 签发／校验 token；缺失或仍是示例值则**拒绝启动** |
| `INIT_ADMIN_EMAIL`／`INIT_ADMIN_PASSWORD` | 仅 `npm run seed` 首次初始化管理员用；初始化后应移除 |
| `INIT_INVITE_CODES` | 仅 `seed` 用，初始邀请码数量，默认 5 |
| `DB_PATH` | 数据库文件路径；不设时用 `backend/data/sale.db`。**隔离测试／验收时指向临时位置，避免写入正式库** |
| `ADMIN_WEB_DIST` | 管理网站构建产物目录；不设时用 `../admin-web/dist` |

## 独立管理网站（`admin-web/`）

管理员网站是**独立构建的前端**，依赖不进入扩展包。

- 构建基础路径 `/admin/`；开发服务器端口 `5175`，把 `/api` 代理到 `http://localhost:5724`（可用 `ADMIN_WEB_BACKEND_TARGET` 覆盖）。
- 后端由 `backend/src/routes/admin-site.ts` 托管构建产物到 `/admin/`，**只覆盖 `/admin` 与 `/admin/assets/*`**，不影响 `/api` 与健康检查；产物缺失时返回 503 与「尚未构建」提示，不返回模拟页面。
- token **只存网页内存**，不用 localStorage／sessionStorage／Cookie；刷新或关闭页面需重新登录。

**为什么独立构建**：管理站要引入 Ant Design／ProComponents（体积大），必须避免它们进入扩展包；已实测扩展构建产物中**无** Ant Design／ProComponents。

配置文件按模式分流，见 [`10-环境与命令.md`](./10-环境与命令.md#开发期连本地后端)。
