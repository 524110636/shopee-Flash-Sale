# 03 代码地图

> **用途**：找文件在哪、谁负责什么。**不追求完整清单**，只列真实存在且需要知道职责的文件。
> **何时读**：需要定位某个功能在哪个文件、判断新文件该放哪。
> **来源**：原 `AGENTS.md`「完整目录结构」＋`CLAUDE.md`「Project Structure」，合并去重并校正漏项。

## 前端目录

```
entrypoints/                    # WXT 入口点
├── popup/                      # 弹窗 UI（viewport=420px）
│   ├── App.tsx                 # 主应用组件（功能首页 ↔ 限时特卖工作页导航 + 面板切换 + 向导各阶段 UI）
│   ├── main.tsx                # React 挂载入口
│   ├── index.html              # HTML 模板
│   ├── store.ts                # Zustand 状态管理 + 全部业务逻辑
│   ├── api.ts                  # GraphQL 商品查询（fetchProducts）
│   ├── backend-api.ts          # 后端 REST API 客户端（auth、stores、analytics）
│   ├── types.ts                # 全局 TypeScript 类型定义
│   ├── one-day-sku.ts          # 1 天备货 SKU 构建器（见下）
│   ├── one-day-sku-task.ts     # 后台修复任务的持久契约与纯决策（payload/结果幂等/孤儿判定/首页摘要）
│   ├── one-day-sku-runner.ts   # 一键修复的后台执行循环与完成结果准备（依赖注入，可单测）
│   ├── PopupPolicyHost.tsx     # 弹窗策略宿主（包住整个 App；通知/强制升级门控 + 查看上报，挂在 main.tsx 最外层）
│   ├── popup-policy.ts         # 弹窗策略：读取/缓存/版本逐段比较/已读记录（按后端地址隔离）
│   ├── popup-views.ts          # 查看统计上报（独立模块，独立超时；不进入策略检查的 5 秒预算）
│   ├── popup-content.ts        # 扩展侧二次安全渲染（DOM 遍历白名单，非正则）
│   └── style.css               # Tailwind 指令
├── background.ts               # Service Worker（开卖循环、复制流程、alarms、自动模式、一键修复 runner、统计上报）
└── content.ts                  # 内容脚本（统一悬浮进度面板、消息中继）

components/
├── ui/                         # shadcn/ui 基础组件（生成区，勿混入业务代码）
│   ├── badge.tsx               # 标签/徽章
│   ├── button.tsx              # 按钮（cva variants: default/destructive/outline/secondary/ghost/link）
│   ├── card.tsx                # 卡片容器（Card, CardHeader, CardTitle, CardContent）
│   ├── input.tsx               # 输入框
│   ├── scroll-area.tsx         # 滚动区域
│   ├── separator.tsx           # 分隔线
│   └── table.tsx               # 表格（Table, TableHeader, TableBody, TableRow, TableCell）
├── lib/
│   └── utils.ts                # shadcn cn() 工具函数（clsx + tailwind-merge）
└── product/                    # 业务组件
    ├── AuthPanel.tsx           # 登录/注册/内联验证码/设置 UI + 使用条款 Modal
    ├── AutoModePanel.tsx       # 自动模式面板（模板选择、场次选择、参数配置、日志）
    ├── CopyConfirmPanel.tsx    # 复制确认面板（时段选择、模板选择、查看）
    ├── CopyResultPanel.tsx     # 复制结果面板
    ├── FeatureHome.tsx         # 功能首页（卡片列表 + 已有任务摘要 + 查看入口；图标用 lucide 组件）
    ├── feature-catalog.ts      # 静态功能定义（id／categoryId／名称／描述／Icon／入口），Icon 为 lucide 组件
    ├── task-summary.ts         # 首页任务摘要纯函数（由真实任务状态派生，不依赖浏览器 API）
    ├── FirstUseModal.tsx       # 第一次使用：分页获取店铺全部商品 + 搜索 + 勾选 + 触发一键修复
    ├── FirstUseWarningModal.tsx# 首次使用前置提醒（须先移除其他促销活动），支持「以后不再提示」
    ├── ProductCard.tsx         # 单个商品卡片
    ├── ProductList.tsx         # 商品列表（含 SkuTable 弹窗）
    ├── ProductViewModal.tsx    # 商品查看二级窗口（自动模式）
    ├── ScheduledTaskCard.tsx   # 定时任务实时倒计时 + 四步进度（复制模板→创建任务→等待开始→手动开启）
    ├── SkuTable.tsx            # SKU 参数表格（折扣%、限时价、活动库存、限购、批量编辑）
    ├── SpcStatus.tsx           # SPC_CDS 连接状态 + 流程引导
    ├── StoreStatus.tsx         # 店铺绑定状态 + 绑定按钮
    ├── TemplateEditDialog.tsx  # 模板编辑弹窗（分组折叠、分页）
    ├── TemplateManager.tsx     # 模板管理器（保存/加载/导出/导入/编辑）
    ├── TimeSlotModal.tsx       # 场次选择模态窗口（调用 API 获取实时场次）
    └── UndiscountedSkuModal.tsx# 自动模式启动前复核未打折 SKU（可跳过）
```

**`one-day-sku.ts` 导出**：`buildOneDaySkuProductInfo`、`getDiscountRatio`、`buildDiscountRestoreList`、`extractSellableStock`、`generateTierCombinations`、`getHighestModelPrice`（可选 `productInfoModels` 参数）、`hasDedicatedOneDaySku`、`hasAnyOneDayDeliverySku`、`extractSellerDiscounts`、`isFiveTimesPriceError`。

**`one-day-sku-task.ts` 导出**：`ONE_DAY_REPAIR_TASK_KEY`、`ONE_DAY_REPAIR_HEARTBEAT_KEY`、`ONE_DAY_REPAIR_APPLIED_KEY`、`ONE_DAY_REPAIR_REQUEST_KEY`、`ONE_DAY_REPAIR_START_ERROR_KEY`、`ONE_DAY_REPAIR_DIAGNOSTICS_KEY`、`REPAIR_KEEPALIVE_INTERVAL_MS`、`REPAIR_HEARTBEAT_GRACE_MS`、`REPAIR_DIAGNOSTIC_LIMIT`、`createRepairTask`、`patchRepairTask`、`canAdvanceTask`、`isTerminalRepairStatus`、`resolveOrphanedTask`、`buildRepairSummary`、`buildRepairDiagnostic`、`redactDiagnosticReason`、`shouldApplyRepairResult`、`isRepairResultReady`、`nextFlowPhaseAfterApply`、`isFlowPhaseAdvanced`、`isSameOwner`、`verifyRepairOwner`、`isRepairTaskActive`、`itemsWithSentWrites`、`fingerprintCredential`、类型 `OneDayRepairDiagnostic`、`RepairOwnerVerdict`。（`resolveDiscountRate` 在 runner。）

**`one-day-sku-runner.ts` 导出**：`runOneDaySkuRepairTask`（含 `RepairRunnerDeps` 依赖注入）、`buildInitialItems`、`resolveDiscountRate`、`describeConfirmedActions`、`RepairCheckpointSaveError`、`RepairOwnershipError`、`RepairStaleWriteError`、`REPAIR_STEP`。

## 管理网站目录

```
admin-web/                      # 独立管理网站（不在扩展包内，由后端托管到 /admin/）
├── index.html                  # 入口 HTML（title「虾皮限时特卖 · 管理后台」）
├── vite.config.ts              # base=/admin/；dev 端口 5175，/api 与 /popup-assets 代理到后端
├── package.json                # 独立依赖：React 18 + Ant Design 5 + dayjs + TipTap（与扩展的 React 19 互不影响）
└── src/
    ├── main.tsx                # React 挂载入口
    ├── App.tsx                 # 五项菜单布局（用户／绑定／邀请码／统计／弹窗管理）
    ├── api/
    │   ├── admin.ts            # 请求模块（不依赖任何 chrome.*／扩展 API）
    │   └── popup.ts            # 弹窗管理请求模块（草稿/发布/撤回/图片上传/查看明细）
    ├── components/
    │   ├── RichTextEditor.tsx   # TipTap 富文本编辑器（只在管理网站，绝不进扩展包）
    │   └── PopupEditorModal.tsx # 新建／编辑弹窗的空白编辑窗口（标题+富文本+强制更新勾选+500px 预览；强制两组字段顶部对齐）
│   └── PopupViewersModal.tsx # 查看明细窗口（只给当前管理员：账号 + 首次查看时间 + 分页）
│   └── PopupVersionGuide.tsx # 版本修改与升级测试指引（可折叠；文件/字段/行号/构建模式/下载解压加载/核对实际版本）
    ├── auth/
    │   ├── session.ts          # token 只存内存变量（不用 localStorage／sessionStorage／Cookie）
    │   └── AuthContext.tsx     # 登录态、useToken()、401/403 自动登出
    ├── pages/
    │   ├── LoginPage.tsx       # 登录
    │   ├── UsersPage.tsx       # 用户管理（限额／自动模式／试用／删除）
    │   ├── BindingsPage.tsx    # 绑定管理（解绑；缺 shopId 显示「店铺信息待补全」）
    │   ├── InviteCodesPage.tsx # 邀请码（生成 1–20／删除未使用）
    │   ├── AnalyticsPage.tsx   # 使用统计（最多 100 条明细；读取失败与真实 0 分开显示）
    │   └── PopupPage.tsx       # 弹窗管理：**默认列表**（总数／标题／类型／状态／操作）+ 新建／编辑窗口
    └── utils/format.ts         # 时间格式化（历史脏值显示为「时间待补全」）
```

## 后端目录

```
backend/                        # 独立后端服务
├── src/
│   ├── index.ts                # 入口：Hono HTTP 服务 + CORS + 路由挂载 + 健康检查
│   ├── seed.ts                 # 首次部署初始化：从环境变量建管理员 + 初始邀请码（幂等）
│   ├── db/
│   │   ├── schema.ts           # Drizzle ORM 表定义（users, verification_codes, store_bindings, analytics_events, invite_codes, popup_policies, popup_active_slots, popup_assets, popup_views）
│   │   └── index.ts            # SQLite 初始化 + 自动迁移（ALTER TABLE；含旧两模式弹窗结构的幂等迁移）
│   ├── routes/
│   │   ├── auth.ts             # 注册(邀请码)/验证/登录/管理员检查/自动模式权限检查
│   │   ├── stores.ts           # 店铺绑定/列表/校验(validate)/消耗试用(consume-trial)/解绑
│   │   ├── analytics.ts        # 事件上报/个人摘要
│   │   ├── admin.ts            # 管理员接口（用户、限额、自动模式、试用、删除、统计、绑定、邀请码）
│   │   ├── popup.ts            # 弹窗策略：公开只读 /api/extension/popup-policy + 展示上报 /popup-views、管理员**多条记录**列表·新建·按 ID 编辑/发布/撤回·查看明细、图片上传、/popup-assets 资源
│   │   └── admin-site.ts       # 托管 admin-web 构建产物到 /admin/（只覆盖 /admin 与 /admin/assets/*；产物缺失返回 503）
│   ├── middleware/
│   │   └── auth.ts             # JWT 验证 + admin 守卫（adminMiddleware 按 token 的 userId 查库判定，非只看 payload.role）
│   └── utils/
│       ├── jwt.ts              # 签发/验证 JWT（jose, HS256, 7 天；拒绝示例 JWT_SECRET 启动）
│       ├── popup-policy.ts     # 弹窗策略校验与清洗（版本格式/下载地址协议/富文本白名单/图片字节签名）
│       ├── popup-views.ts      # 查看统计（上报校验/去重写入/人数与账号明细查询；独立模块）
│       └── code.ts             # 6 位验证码生成器（5 分钟过期）
├── package.json
└── tsconfig.json
```
